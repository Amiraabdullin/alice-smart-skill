# 🎙 Умный навык для Яндекс Станции (с поддержкой LLM без блокировки музыки)

Готовый бэкенд навыка для Яндекс Алисы (протестирован на Станциях Мини 2 и Лайт). 
Позволяет задавать вопросы современной нейросети (Groq, Gemini, DeepSeek, OpenAI) одной фразой, **не блокируя Яндекс Музыку, будильники и функции умного дома**.

---

## 🌟 Как это работает на колонке

1. Вы говорите:
   > *«Алиса, спроси у **Джина**, как работает квантовый компьютер»*  
   > или *«Алиса, попроси **Джина** составить меню на ужин»*
2. Колонка зачитывает ответ от нейросети.
3. **Навык сразу завершает сессию (`end_session: True`)**.
4. Сразу же следующей фразой можно сказать: *«Алиса, включи рок»* — и музыка включится без лишних слов и выходов из навыка.

## 🚀 Варианты развертывания

### Вариант 1. Бесплатный хостинг Vercel (Рекомендуется)
Vercel идеально подходит для Алисы, так как бессерверные функции просыпаются за **1 секунду** (нет тайм-аутов).

1. Загрузите эту папку в свой GitHub-репозиторий.
2. Войдите на [vercel.com](https://vercel.com) через GitHub.
3. Нажмите **«Add New Project»** и выберите репозиторий.
4. В разделе **Environment Variables** добавьте один ключ:
   * `GROQ_API_KEY` — ключ от Groq (рекомендуется).
5. Нажмите **Deploy**. Vercel выдаст ссылку: `https://your-project.vercel.app`.
6. Ваш Webhook URL для Яндекса: `https://your-project.vercel.app/webhook`.

---

### Вариант 2. Бесплатный хостинг Render.com
1. Загрузите проект на GitHub.
2. Войдите на [render.com](https://render.com) ➔ **New Web Service** ➔ выберите репозиторий.
3. Build Command: `pip install -r requirements.txt`
4. Start Command: `gunicorn main:app`
5. В Environment Variables укажите ваш `GROQ_API_KEY` (или `GEMINI_API_KEY`).
6. Скопируйте полученную ссылку (например, `https://my-skill.onrender.com/webhook`).

---

### Вариант 3. Запуск локально на компьютере (для теста)
1. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
2. Запустите сервер:
   ```bash
   python main.py
   ```
3. Для проброса HTTPS в Яндекс используйте утилиту туннелирования (например, Cloudflare Tunnel или ngrok):
   ```bash
   cloudflared tunnel --url http://localhost:8080
   ```

## 🔑 Где взять бесплатный API-ключ

* **Groq (Самый лучший выбор):**  
  👉 [console.groq.com/keys](https://console.groq.com/keys)  
  *Отклик всего 200–300 мс — Алиса никогда не скажет «Навык не отвечает». Регистрация за 30 секунд через Google/GitHub, полностью бесплатно.*

* **Google Gemini:**  
  👉 [aistudio.google.com](https://aistudio.google.com/)  
  *Вход через Google-аккаунт ➔ Create API key. 15 запросов в минуту бесплатно.*

## 🛠 Настройка в консоли Яндекс Диалогов

1. Откройте [dialogs.yandex.ru/developer](https://dialogs.yandex.ru/developer) под своим Яндекс-аккаунтом.
2. Нажмите **«Создать диалог»** ➔ выберите **«Навык в Алисе»**.
3. Заполните поля:
   * **Название:** *Джин* (или любое удобное вам имя).
   * **Активационное имя:** то же самое (например, *джин*).
   * **Backend:** выберите **Webhook URL** и вставьте ссылку вашего сервера (`.../webhook`).
   * **Приватность:** отметьте **«Не публиковать в каталоге»** (навык будет доступен только вам на ваших Станциях).
4. Внизу нажмите кнопку **«Сохранить»** и затем **«Опубликовать»** (приватный навык активируется мгновенно на ваших колонках без долгой модерации).

## 📁 Структура проекта
* `main.py` — Flask-сервер с защитой от тайм-аутов, фильтрацией markdown (чтобы Алиса не читала звёздочки голосом) и флагом `end_session: True`.
* `test_skill.py` — скрипт локальной проверки без интернета.
* `requirements.txt` — зависимости Python.
* `render.yaml` — конфигурация для быстрого деплоя на Render.
* `vercel.json` — конфигурация для мгновенного деплоя на Vercel.
* `.env.example` — шаблон переменных окружения.
